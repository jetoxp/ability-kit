# Working notes

These are the working notes of each phase, written **at the time of that phase** and kept as an audit
trail: the bugs, the wrong turns, and the corrections they forced. They are historical documents.

**Where one of these notes and the root [`README.md`](../../README.md) disagree, the README is
current.** The notes record what was believed, measured and decided at that moment; later phases
corrected some of it — a count here, a shape there, a claim that a later playtest refuted. Numbers,
shapes and claims in this folder are historical by design, and the phase that supersedes them is the
later file, not the earlier one.
